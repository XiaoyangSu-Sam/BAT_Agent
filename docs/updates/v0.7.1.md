# Update to BAT Agent v0.7.1

This update starts from v0.7.0. It adds conversation approval choices, saved model switching and connection status, a colored context ring, and a smaller resizable composer. Ordinary chat instructions now guide the assistant to identify goals, constraints and verification steps. Python and frontend dependencies are unchanged.

## Import and verify

Use the existing [source update workflow](../existing-environment.md). Keep the existing model and execution settings, interpreter, Skills, Git and workspace. Back up the stopped state before launch. Startup adds a nullable approval_mode column. Older conversations inherit the project policy and retain their existing grants. Restore the pre-update state backup as well as the source when rolling back. A code-only rollback can leave later policy choices ineffective.

- Add two test connections and select each from settings and the composer. Confirm each request reaches its own endpoint. Check the header for successful and failed probes.
- Verify Ask for approval pauses before an agent write and an execution. Verify Approval for me prompts for execution and offers Allow all. Verify Full access runs a test script without a prompt and applies only to that conversation.
- Confirm the context ring changes from green to yellow at 70% and red at 90%. For a connection without measured token usage or confirmed context capacity, confirm the Local label. Check that the composer starts compact and can resize.

The [development guide](../development.md) records the next work in order, with Plan Mode followed by conversation compaction.
